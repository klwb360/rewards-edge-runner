# Microsoft Rewards 本机操作流程

适用环境：Windows、已安装的 Microsoft Edge、Python 3.10 及以上、单个个人 Rewards 账户。双击项目中的 `Rewards.bat` 打开菜单，也可在项目目录的 PowerShell 中使用下列命令。

Ubuntu/Debian 服务器请使用 [Linux 部署指南](LINUX_DEPLOYMENT.md)。两个平台共用 Python 核心和报告格式；Windows 保留现有 BAT 菜单。

## 首次使用

1. 双击 `Rewards.bat`，选择安装环境，或运行 `.\Rewards.bat setup`。
2. 选择手动登录，或运行 `.\Rewards.bat login`。在独立 Edge 窗口中处理密码、双重验证及验证码，进入个人 Rewards 仪表板后，返回终端按 Enter。
3. 运行 `.\Rewards.bat inspect`，核对活动列表。这一步只检查，不点击任务、不搜索。
4. 运行 `.\Rewards.bat config` 检查配置；需要更换搜索主题时，将 `searches.example.txt` 复制为 `searches.txt`，每行填写一个主题，再修改 `search_terms_file`。
5. 运行 `.\Rewards.bat run`，结束后使用 `.\Rewards.bat report` 查看报告。

脚本的 Edge 会话保存在 `.state/profile`，与日常使用的 Edge 配置独立。会话失效时再次执行 `login`；不在配置中保存密码。`.state/` 含有效登录会话，请勿上传或分享。

## 每日运行与结果核对

```powershell
.\Rewards.bat inspect
.\Rewards.bat run
.\Rewards.bat report
```

随附配置最多尝试 12 项网页活动和 20 条不同搜索词，搜索等待 15 秒，`verify_search_points` 为 `true`；搜索后继续核验 Edge 浏览分钟。Edge 最多等待 60 分钟，每 60 秒读取一次实际进度。这些是程序上限和等待设置，不是保证获得的积分。

网页活动同时检查首页每日活动和“积分赚取”页的日常任务，跳过已完成项目。新版卡片先等待 React 交互处理程序就绪，再执行可见卡片的普通点击。打开目标页面后返回所属页面，只有同一活动 ID 的完成标记明确变为真，才记录 `completed`；冲突、未知或未确认的状态留待检查。

Bing 搜索通过搜索框填写词条并按 Enter 提交，随后读取“今日积分 → 积分明细”的真实搜索计数。已满额时不再打开搜索页面；运行中达到上限立即停止；连续两次未观察到增加时暂停该搜索阶段。若 Edge 阶段已启用，会继续核验 Edge，整轮仍保留部分失败。出现搜索暂停时先看报告和网页提示，勿连续重跑尝试凑分。

Edge 阶段要求可见的 Microsoft Edge；配置应为 `channel: msedge`、`headless: false`、`edge_daily_enabled: true`。首次需要在独立 Edge 中登录个人 Microsoft 账户。页面已经确认今日完成且分钟达标时立即跳过；未满时进入官方浏览入口，保持窗口并定期查看后台观察页的数据。允许正常浏览，轮询不会反复抢占焦点。

Edge 的本地计时只控制最长等待时间，任务完成以页面返回的分钟数和今日标记为准。60 分钟后仍未确认、任务未开放等情况记为未完成，返回 `1`；登录/验证码和日期/页面变化分别按原错误类别停止。按 Ctrl+C 会保存最后观察结果，返回 `130`。旧配置没有 Edge 开关时维持原行为。

查看最新 JSON 时重点核对：

| 字段 | 如何判断 |
| --- | --- |
| `tasks[].status` | `already_completed` 表示运行前已经完成；`completed` 表示仪表板确认完成 |
| `searches.quota_before` / `quota_after` | 实际开始与结束进度，含账户显示的当前值和上限 |
| `searches.observed_points_gained` | 本轮观察到的搜索积分增量 |
| `searches.credit` | `observed` 为观察到正向变化；`unverified` 表示未确认计分 |
| `searches.stopped_reason` | `limit_reached` 为满额；`no_credit` 为连续未计分而停止 |
| `edge_browsing` | 对照执行前后分钟、目标分钟和今日完成标记；本地等待时间不能替代完成证明 |

顶层 `status: completed` 表示本次全部启用阶段正常结束，**不代表所有手机任务完成，也不单独证明搜索满额**。搜索是否满额必须对照 `quota_after`，Edge 是否完成必须对照实际分钟与今日标记；任何部分失败都不会被后续阶段的成功覆盖。

每条词在提交前写入当天历史，保存的是哈希；中断或请求失败后，当天也会跳过该词。更改搜索次数或词条文件可能让本轮选中当天尚未提交的新词。历史去重不等于积分核验，建议保持 `verify_search_points: true`。

## 安装、查看与移除每日计划

计划任务需要手动安装；本流程记录时尚未启用。先确认登录有效和单次运行结果，再执行：

```powershell
.\Rewards.bat schedule-install -At 20:00
.\Rewards.bat schedule-show
```

时间采用 `config.json` 中的 `timezone`；随附配置为 `Asia/Shanghai`，默认 20:00 即北京时间 20:00。旧配置省略时区或使用 `null` 时沿用本机时间。日期选择、搜索历史、跨日检查和 JSON 报告也使用同一时区，不修改 Windows 系统时区。Windows 每日触发器使用固定时差；安装时拒绝有季节性时差变化的时区，避免夏令时后静默偏移；`Asia/Shanghai` 和 `UTC` 可用。

电脑必须开机且当前 Windows 用户已登录；任务不会自动开机或唤醒电脑，电池供电时也可能跳过。任务使用当前用户普通权限。新安装或显式更新后的总运行时限为 120 分钟，为 Edge 长阶段保留余量；已有计划需要重新执行安装命令才会更新时限。

```powershell
.\Rewards.bat schedule-remove
```

移动项目目录前，先在**旧目录**移除任务；移动后在新目录执行 `setup`、检查登录和单次运行，再安装计划。任务按目录区分，从新目录移除不会清理旧目录对应的任务。移除计划不删除登录会话、报告或历史。

## 验证与适用范围

测试覆盖活动完成标记核验、卡片交互就绪、搜索计数读取、满额停止、连续未计分停止、当天去重和 Windows 启动入口。访问类日常活动及搜索计分也经过实际账户验证。实际额度和任务资格由微软针对账户、地区及日期决定，本项目不保证固定积分。

Edge 阶段通过隔离页面和模拟时钟验证已满跳过、进度增长、完成标记冲突、停滞和超时、任务缺失、登录失效、跨日及中断。真实账户验收目前只确认 `30/30` 且今日完成时自动跳过、等待 `0` 秒；尚未验证真实未满任务增长至完成的完整计时过程，需要在任务未满时另行验收。

个人积分余额、登录会话、运行日志和本地验收记录不属于公开源码，已由 `.gitignore` 排除。请自行保留运行报告以核对结果，不要将含账户信息的文件提交到公开仓库。

当前程序不处理原生手机阅读/签到、Xbox 实际游戏、购买、兑换、抽奖、捐赠或待领取积分。复杂测验和投票仅经过隔离页面测试，尚未完成真实未完成测验的验收；投票会尝试首个可点击选项，测验不保证答对。

手机必应 App 的阅读任务，需要在手机登录同一账户，打开 Rewards 中的“阅读以赚取”，按该任务入口和提示正常阅读，再返回查看进度是否增加。入口可能随账户、地区和版本变化；不保证每篇积分、文章数量或停留时长。请以 App 显示的进度核验阅读任务。

MSN 桌面阅读已做过一次有限测试：同一独立 Edge 会话依次打开 4 篇 `www.msn.cn` 新闻，逐篇查看 Rewards 明细；后 3 篇各停留 60 秒，未观察到今日积分增加，测试中手机阅读计数仍为 `0/30`。已在第 4 篇后停止，未将此方式接入每日运行。这只说明本次桌面网页尝试未验证计分，不能推断手机 App 的阅读规则，也未确定有效的浏览时间或计分间隔。

## 排查与其他命令

| 退出码 | 处理方式 |
| --- | --- |
| `0` | 登录/检查成功，或本次流程正常结束；仍需查看报告中的任务和搜索进度 |
| `1` | 有未完成项目、搜索未计分而暂停或运行错误；先查看最新报告的原因 |
| `2` | 需要人工登录或验证；执行 `login`，完成后再检查 |
| `3` | 页面结构或日期数据不兼容；保存报告，核对日期和实际页面后再适配 |
| `130` | 用户中断；报告保留最后实际观察到的进度，可稍后检查再运行 |
| `143` | 收到 SIGTERM；报告保留最后观察结果，Linux 停止服务时使用此退出码 |

```powershell
.\Rewards.bat logs     # 查看日志目录
.\Rewards.bat config   # 编辑配置
.\Rewards.bat guide    # 查看本流程
.\Rewards.bat help     # 查看支持的命令
.\Rewards.bat doctor   # 本机配置、依赖及 Edge 位置检查，不启动浏览器
```

每次运行的 JSON 报告和滚动日志保存在 `.logs/`。缺少 Python/依赖时先执行 `setup`；页面改变或持续不计分时保留报告，不清空历史反复尝试。微软禁止通过机器人、宏等自动方式获取 Rewards 积分，使用脚本可能导致账户限制或积分失效，规则说明见项目 [README](../README.md)。
